Detailed Description

A chain of branches, the first of which whose condition holds is applied.

A chain is started by DriverBase::when(input_key, value), which starts its first branch. Each branch holds wiring requests: fixed values, set with set_input and set_submod, and inputs and submodules of the driver, which are forwarded with forward_input and forward_submod. Further branches are started with otherwise(input_key, value), and a final branch, which applies if no condition holds, with otherwise().

When the driver is locked, the conditions are tested in the order the branches were declared, and only the requests of the first branch whose condition holds are applied. A condition holds if the driver's input input_key equals value.

The functions which add requests act on the most recently started branch.
