Detailed Description

A submodule of a driver, as it is declared.

DriverBase::add_submodule returns a DriverSubmodule, rather than the SubmoduleRequest ModuleBase::add_submodule returns. It adds set_default, which names the module bound to the submodule if the user binds none, and set_target and set_required_target, which request that the module bound to the submodule is also bound to a submodule of a module below the driver.

DriverSubmodule & pluginplay::DriverSubmodule::set_default ( qualified_key  submod_key)
inline

Names the module bound to the submodule if the user binds none.

Modules are found by key, so the submodule can not be bound in the driver's constructor. The default is recorded in the driver's request and bound by the ModuleManager when it resolves the driver's requests, if the submodule is still unbound. It should be a module of the driver's own plugin.

Parameters
