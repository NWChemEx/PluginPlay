Detailed Description

Base class for all plugins.

A plugin is a named collection of modules. Plugins are written like modules: the derived class's constructor calls the protected member functions of this class to set the plugin's name, add its modules, wire its modules together, and record which modules from other plugins it would like to use as default submodules. After construction the plugin is read-only through its public interface.

See the "Designing the Plugin Class" page of the developer documentation for the design.

Records a default submodule from another plugin.

If provider is loaded, wiring sets the submodule callback_key of this plugin's module module_key to the provider's module provider_key, unless the submodule is already set.

Parameters
[in]providerThe name of the plugin providing the module.
[in]module_keyThe key of this plugin's module.
[in]callback_keyThe key module_key uses for the submodule.
[in]provider_keyThe key of the provider's module.
Exceptions
std::invalid_argumentif provider is not a preferred provider. Strong throw guarantee.
std::out_of_rangeif module_key is not one of this plugin's modules, or if callback_key is not a submodule of module_key. Strong throw guarantee.

Determines if name can be used as a plugin name.

Plugin names must be identifiers: a letter or an underscore, followed by letters, digits, and underscores, e.g., "my_plugin". Plugin names are used as directory names (see printing::document_modules) and in module cache names, so they can not contain spaces, path separators, or "::".

Parameters
[in]nameThe name to check.
Returns
True if name is a valid plugin name and false otherwise.
