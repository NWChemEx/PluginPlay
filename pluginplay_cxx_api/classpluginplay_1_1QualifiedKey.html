Detailed Description

Identifies a module in a ModuleManager.

A ModuleManager holds one ModuleMap per loaded plugin, plus a ModuleMap of its own. Module keys are unique within a map, but two maps may use the same key. A QualifiedKey names a module in one of two ways:

  • key-only, e.g., "Overlap". The ModuleManager searches every map for the key. This is the form created implicitly from a string, so code that passes a plain module key keeps working.
  • qualified, e.g., {"integrals", "Overlap"}. The ModuleManager only looks in the named plugin's map. The empty plugin name, "", names the ModuleManager's own map. Hence {"", "Overlap"} is qualified and is not the same as "Overlap": it is the only way to reach the ModuleManager's own "Overlap" when a plugin also has one.

Like module keys and plugin names elsewhere in PluginPlay, both the plugin name and the module key are compared case-insensitively.
