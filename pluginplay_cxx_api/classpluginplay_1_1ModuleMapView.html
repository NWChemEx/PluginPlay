Detailed Description

A read-only view of a ModuleMap, for the Python bindings.

C++ can hand out a const ModuleMap&, but Python has no const, so a ModuleMap returned to Python could be changed through ModuleMap's bindings, e.g., have modules added that never receive the ModuleManager's runtime and caches. Functions that return a read-only ModuleMap to Python return a ModuleMapView instead, which only exposes the read-only members.

The view does not own the map; the bindings keep the map's owner alive for as long as the view exists. The modules themselves can still be changed (e.g., their inputs), just as with ModuleManager.at, and at returns them with shared ownership.
