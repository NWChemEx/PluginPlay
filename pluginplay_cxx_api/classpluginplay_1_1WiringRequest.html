Detailed Description

One input or submodule a driver sets on a module below it.

A wiring request names a target, i.e., a module key and either an input or submodule of that module, and what the target should be set to. There are four kinds of requests:

  • set_input sets the target input to a fixed value,
  • set_submod binds the target submodule to the module with a given key,
  • forward_input sets the target input to the value of one of the driver's inputs, and
  • forward_submod binds the target submodule to the module bound to one of the driver's submodules.

Wiring requests are data. They name modules by key, and are resolved by the ModuleManager when the driver is locked. Requests are made through CallGraphRequest, ConditionalWiring, DriverInput, and DriverSubmodule.
