Detailed Description

An input of a driver, as it is declared.

DriverBase::add_input returns a DriverInput, rather than the ModuleInput ModuleBase::add_input returns. It has the chainable setters of ModuleInput, which forward to the input, and adds set_target and set_required_target, which request that the value of the input is also set on a module below the driver.

A DriverInput holds references to the input and to the driver's request. It holds no state of its own and can be discarded once the chain ends.
