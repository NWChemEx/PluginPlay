Detailed Description

A container of modules, indexed by module key.

ModuleMap is a thin wrapper around a case-insensitive map from module key to module. It decouples creating modules from storing them in a ModuleManager, e.g., a Plugin builds a ModuleMap in its constructor without needing a ModuleManager.

Copies of a ModuleMap are shallow, i.e., the copy and the original share the same Module objects.
