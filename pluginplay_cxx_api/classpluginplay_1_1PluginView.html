Detailed Description

A read-only view of a Plugin, for the Python bindings.

ModuleManager::get_plugin returns a const Plugin&. Python has no const, and the Plugin bindings include the setters a plugin written in Python uses in its constructor, so a loaded plugin returned to Python as a Plugin could be changed. ModuleManager.get_plugin returns a PluginView instead, which only exposes Plugin's read-only members.

The view does not own the plugin; the bindings keep the plugin's owner alive for as long as the view exists.
