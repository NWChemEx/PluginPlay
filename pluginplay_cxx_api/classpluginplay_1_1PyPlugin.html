Detailed Description

The class Python plugins derive from.

Plugin's constructor is protected, so pybind11 cannot create a Plugin directly. PyPlugin makes the constructor public. Plugin has no virtual functions to forward to Python.

ModuleManager::load_plugin takes ownership of the plugin away from Python. Deriving from trampoline_self_life_support keeps the Python part of a plugin written in Python (e.g., its Python modules) alive for as long as the ModuleManager owns the plugin.
